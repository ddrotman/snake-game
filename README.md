# Snake

A classic Snake game in a single HTML file — no dependencies.

## Play

Open `index.html` in a browser.

- **Arrow keys / WASD** — move
- **Space** — pause/resume
- **Enter** — restart after game over
- **Swipe** — move on touch devices (tap to restart)

Eat the red food to grow. Don't hit the walls or yourself. Your best score is saved locally.
